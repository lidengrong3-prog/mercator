一、致命问题（3个）
F-01 | 无浏览器历史路由支持 — 前进/后退按钮失效、URL分享无效
• 问题描述：switchPage() 函数通过 [data-page] 的 click 事件实现页面切换，但源码中 **没有任何 hashchange 监听器、history.pushState、history.replaceState**。虽然侧边栏 <a> 标签有 href="#countries" 等属性，但这些 hash 变化不会触发页面切换。用户点击浏览器"后退"按钮不会回到上一个浏览的页面，复制 URL 分享给他人也无法打开对应页面。
• 所在页面：全站
• 截图：无法截图
• 严重程度：致命
• 普通人困惑："我点了浏览器后退键，怎么页面没回到刚才看的？把这个链接发给同事，他打开后看到的也不是我想给他看的那个页面。"
F-02 | 报告导出功能完全未实现 — 按钮点击只弹 toast 提示
• 问题描述：rpExportAll() 函数体为 toast('报告导出功能将在下一版本上线')，点击"导出报告"按钮只弹出一行提示文字，没有任何实际的导出行为。同理，plExportReport() 函数体为 toast('政策动态报告导出功能（企业版）')。产品雷达的 pr-batch-export 按钮点击后也仅 toast 提示。多处核心导出功能均为占位符。
• 所在页面：报告生成中心、政策动态、产品全域雷达
• 截图：无法截图
• 严重程度：致命（核心功能缺失）
• 普通人困惑："我点了'导出报告'，结果什么都不会发生？只弹了个提示说下一版本？那这个功能现在到底有没有？"
F-03 | AI搜索功能依赖外部 API Key — 用户可能无法使用
• 问题描述：AI 搜索调用 DeepSeek API（baseURL: https://api.deepseek.com，model: deepseek-v4-pro）。API Key 通过 aiInitKeyUI() 函数从 localStorage 读取，如果用户未配置 key，搜索功能将不可用。默认 demo 用户（'陆安然'）是否有预置 key 不确定。搜索框下方虽有6个快捷提示标签，但搜索结果的渲染依赖异步 API 调用成功。
• 所在页面：首页/总览
• 截图：无法截图
• 严重程度：致命（若 key 无效则核心功能缺失）
• 普通人困惑："我输入了'美妆'然后按回车，但什么也没发生。是网络问题还是这功能不好使？"
