| `index.html` | 应用页面结构和所有业务板块入口 | 是 |

## 本地生成文件

下列内容不属于源代码，出现后通常无需提交：

- `node_modules`：Node 依赖。
- `test-results`、`playwright-report`：浏览器测试结果。
- `__pycache__`、`*.pyc`：Python 缓存。
- `*.log`：本地服务和诊断日志。
- `.env`：本地密钥，只能保存在本机并由 `.gitignore` 排除。
