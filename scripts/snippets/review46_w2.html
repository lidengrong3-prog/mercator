❓ 常见问题（FAQ）

关于 JAY观海 的使用与数据说明

  • JAY观海 是什么？JAY = 际安云，观海 = 监测全球数据。我们是一套面向中国产业带工厂的跨境市场情报系统，覆盖 26 国、41 个电商平台，帮你低成本判断"货该卖到哪国、怎么避坑"。
  • 数据是实时的吗？系统提供"数据定时刷新"（默认每 2 小时），侧边栏底部可查看刷新状态与更新日志。部分指标为行业估算，仅供决策参考。
  • AI 搜索需要配置 Key 吗？不需要。未配置外部 API Key 时，AI 搜索会自动使用本地规则引擎给出市场机会与风险提示；配置 DeepSeek Key 后可获得更强的语义分析。
  • 免费版能用什么？免费版可浏览全部市场/平台/政策数据、使用 AI 搜索与定时刷新、生成并导出报告。部分批量操作与高级企业协同功能需升级专业版（PRO）。
  • 为什么有些平台显示"N/A"？个别平台因公开数据缺失，增速/客单价暂以 N/A 显示。我们正持续补全，不影响其余维度的参考。
  • 报告怎么导出？在"报告生成中心"点"生成报告"后，点"导出报告"即可下载 HTML 格式报告；政策与产品雷达也支持 CSV/Excel/PDF 导出。
